# M6 视觉 PID 模块使用文档

视觉 PID 根据目标在画面中的位置和面积生成前进、垂直速度及偏航角速度，
以 50Hz 发布 `/ctrl/visual` 中间指令。本模块不直接连接飞控。

## 输入与输出

| 方向 | ROS 话题 | 消息类型 |
|---|---|---|
| 输入 | `/visual/tracks` | `uav_tracking/VisualTrackArray` |
| 输出 | `/ctrl/visual` | `mavros_msgs/PositionTarget` |

输入目标包含 `id`、像素框 `bbox=(x,y,w,h)` 和 `area_ratio`（目标框面积/图像面积）。
图像尺寸必须与配置一致，默认为 640×480。输出保持 `frame=9`、`type_mask=1479`，
启用三轴速度和 yaw_rate，其中 `velocity.y` 明确为 0。

## 如何启动与验证

在项目根目录加载已构建的 ROS Noetic 工作区：

```bash
source /opt/ros/noetic/setup.bash
source catkin_ws/devel/setup.bash
bash test/pid_controller/e2e_test/run_e2e.sh
```

隔离脚本使用独立 master、临时 ROS_HOME、独立节点名和全部话题重映射，提供中心及
偏移目标，检查输出符号、frame/mask、频率和静默后的零速。

只启动 PID 节点时，在专用测试 ROS master 环境中执行：

```bash
roslaunch uav_tracking pid_controller.launch
```

该 launch 只启动 PID 并加载
[pid_controller.yaml](../../catkin_ws/src/uav_tracking/config/pid_controller.yaml)，
不会启动视觉检测或跟踪器。测试目标需由独立数据源提供；共享 ROS master 中先使用
隔离脚本，避免影响同名节点。YAML 可配置发布频率、保持时间、图像尺寸及面积相关参数；
三通道 PID 增益和限幅当前从 `code/config.py` 读取，不是节点私有 ROS 参数。

## 选择规则与预期效果

多目标选择 `area_ratio` 最大者；面积相同选 `id` 最小者。ROS 侧 body 速度采用 FLU：
x 前、y 左、z 上。默认正增益下：

| 输入 | 预期输出趋势 |
|---|---|
| 画面中心、期望面积 | 无历史积分/微分影响时，速度和 yaw_rate 接近 0 |
| 目标在右侧 / 左侧 | yaw_rate 为负 / 正 |
| 目标在下方 / 上方 | velocity.z 为负 / 正 |
| 面积小于期望值（远目标） | velocity.x 为正，向前逼近 |
| 面积大于期望值（近目标） | 深度通道趋向非正；达到末端面积阈值后使用配置的末端速度 |

模块采用直接面积误差：

```text
safe_area = max(area_ratio, min_area)
depth_output = depth_pid.compute(desired_area, safe_area, dt)
```

这是 M6 的实现选择，输出仍受限幅和末端策略约束。默认期望面积 0.10、最小面积
`1e-4`、正向速度上限 2.0、末端面积阈值 0.35、末端前进速度 0.0。

## 丢失与使用边界

非空数组刷新有效时间；空数组不刷新。短时无目标时保持上一条命令；距最后非空
输入超过 0.2 秒，无论持续空数组还是完全断流，都输出三轴零速度和零 yaw_rate。
0.2 秒按时间计算，不随 50Hz 发布频率改变。

FLU/FRD 等后续转换由 MAVROS 负责，项目节点不重复转换。节点不发布
`/mavros/setpoint_raw/local`，隔离脚本不启动 control_mux、state_machine、MAVROS
或 OFFBOARD，不调用飞控服务、不解锁、不起飞。当前参数尚未经过真实飞行器闭环调参。
