# 模块 6 实现说明

本文件是本地实现补充，不修改 `design/` 中的 develop 原文。

## 纯算法接口

- `PIDController.compute(setpoint, measurement, dt) -> float`
- `command_from_track(...) -> PositionCommand`
- `stop_setpoint() -> PositionCommand`
- `on_timer(...) -> PositionCommand`

正式算法输出类型只有公共 `PositionCommand`。纯算法不导入 `rospy`、
`geometry_msgs` 或 `mavros_msgs`。

实际调用链为：

```text
VisualTrack.msg -> tracks_from_msg -> VisualTrack -> select_track
-> command_from_track -> PositionCommand
PositionCommand -> command_to_position_target -> PositionTarget
```

多目标按 `area_ratio` 最大、相同面积按 `id` 最小选择。偏航、垂直和深度通道
分别生成 `yaw_rate`、`velocity.z` 和 `velocity.x`。

## ROS 节点适配

`pid_controller_node.py` 将 `VisualTrackArray` 拆为纯 `VisualTrack`，把
`PositionCommand` 装包为 `mavros_msgs/PositionTarget`，并以 50Hz 发布
`/ctrl/visual`。输出保持 `FRAME_BODY_OFFSET_NED=9`、`type_mask=1479`，显式
写入 `velocity.y=0.0`；节点不发布最终飞控话题。

非空目标刷新有效时间；0.2s 内重发上一条速度命令，超时或上游断流后输出全零
速度和偏航角速度。多目标按 `area_ratio` 最大、相同面积按 `id` 最小选择。

默认配置为 `PID_RATE_HZ=50.0`、`PID_HOLD_TIMEOUT=0.2s`、图像尺寸 640x480、
期望面积 0.10、最小面积 `1e-4`、正向速度上限 2.0、末端面积阈值 0.35 和末端
前进速度 0.0。PID 增益、输出限幅和积分限幅统一位于 `code/config.py`。

## 验证边界

测试覆盖 PID 限幅、面积保护、方向符号、末端阈值、目标选择、`dt<=0`、掩码、
50Hz 配置和断流安全输出。隔离 E2E 只验证中间话题，不启动控制链或飞控。

ROS 侧 body 速度采用 FLU 语义：x 前、y 左、z 上。项目节点不进行 FLU/FRD 或
ENU/NED 二次转换；完整 MAVROS/PX4 飞行闭环和真实飞行器 PID 调参尚未验证。

本轮收尾验证中，完整 pytest 为 `193 passed`，`catkin_make` 成功；PID 隔离 E2E
收到 131 条输出，实测 `49.99Hz`，中心/方向/停止分支均通过，掩码为 `1479`。
